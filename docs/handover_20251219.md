## 2) `RUNNING / FILLED / CLOSED` の意味（高校生向け）
- `ORDERED`：先回りの指値を「置いた」状態（まだ約定していない）
- `RUNNING`：指値が当たって「約定した」ので、ポジション保有中（この後、利確/損切りを待つ）
- `tp_demo / sl_demo` の `FILLED`：利確（TP）または損切り（SL）の「決済注文」が当たった状態
- `preplace_demo` の `CLOSED`：その銘柄の取引が「決済まで終わった」状態（結果確定）
- `CANCELLED_AUTO`：片側が約定したので、反対側の先回り注文などを自動で取り消した
