# 引継ぎ 2025-12-20（週末バッチ差分更新＋異常時フル探索）

## 目的（何を変えたか）

週末バッチ（VM）の計算時間と失敗リスクを減らすために、毎週「全部の銘柄に全部の探索」をやり直すのではなく、

- **新しく入ってきた銘柄**
- **直近10営業日で調子が悪い銘柄（異常扱い）**
- **月1回のリセット（フル探索）**

だけをフル探索し、その他の「いつも上位にいる銘柄」は **前回の結果を再利用**する運用を追加しました。

重要: 「精度を落とすためにプラン数や試す組み合わせ数を減らす」のではなく、**“やり直しが必要な銘柄だけ”を選別して計算量を減らす**方針です。

---

## 何が動くようになったか（仕組み）

### 1) 日次（Windows 18:00 の DailyReplay）

`analysis/daily_trades_YYYYMMDD.csv`（日次の仮想売買の結果）から、
直近10営業日ぶんを集計して「異常扱い（次の週末にフル探索したい銘柄）」を作ります。

- 生成: `tools/build_abnormal_codes.py`
- 出力: `data/universe/abnormal_codes_latest.csv`（最新）＋ `data/universe/abnormal_codes_YYYYMMDD.csv`（日付スナップショット）
- 連携: `scripts/run_daily_replay.ps1` が best-effort で GCS にアップロードします  
  `gs://asagage-weekend-output/universe/abnormal_codes_latest.csv`

異常の判定（ベース）:
- 直近10営業日で取引回数が一定以上（デフォルト5）ある銘柄について
- 合計損益がマイナス、または PF<1.0、または 勝率<0.5

### 2) 週次（VM 16:30 の weekend バッチ）

`scripts/nightly_build_candidates.py` に **週末差分更新モード**を追加しました。

- `--weekend-incremental`: 差分更新を有効化
- `--weekend-monthly-reset`: 毎月「最初の金曜」はフル探索
- `--weekend-force-full-reset`: 強制フル探索（手動デバッグ用）

仕組み（ざっくり）:
- 週末のTop300（→VWAPフィルタ後のユニバース）を `universe_codes` とする
- `data/universe/top_regulars_ever.csv` に含まれない銘柄は「新規」→フル探索
- `data/universe/abnormal_codes_latest.csv` に含まれる銘柄は「異常」→フル探索
- それ以外は「再利用」→前回週末の `output/excel/candidates_for_YYYYMMDD.csv` から該当行を残す

VM 側の `vm_run_weekend_only.sh` は以下も best-effort で実施します:
- `tools/build_top_regulars_universe.py --update-ever` を実行し、Top200常連（ever）CSVを更新
- `gs://asagage-weekend-output/universe/abnormal_codes_latest.csv` を取得して `data/universe/abnormal_codes_latest.csv` に保存
- `--weekend-incremental --weekend-monthly-reset` を付けて週末バッチを実行（環境変数で強制フル探索も可）

## 重要なファイル（どれを見れば良いか）

- 異常銘柄リスト（Windows生成）: `data/universe/abnormal_codes_latest.csv`
- Top200常連（ever）: `data/universe/top_regulars_ever.csv`
- 週末バッチ（VM側）実行ログ: `~/cloud_logs/weekend_YYYYMMDD_HHMMSS.log`
- 週末の最終候補: `output/excel/candidates_nextday.csv`（Excel取り込み対象）
- 当日スナップショット: `output/excel/candidates_for_YYYYMMDD.csv`

## 運用メモ（迷ったときの判断）

### 月1回のフル探索
- `--weekend-monthly-reset` により「毎月最初の金曜」はフル探索になります。

### 異常時のフル探索（直近10営業日）
- DailyReplay の結果から自動で `abnormal_codes_latest.csv` を作り、週末でその銘柄だけフル探索します。

### 手動でフル探索したいとき（例: 大きな仕様変更直後）
VM で実行する際に `WEEKEND_FORCE_FULL_RESET=1` を付けます。

例:
- `WEEKEND_FORCE_FULL_RESET=1 bash run_weekend_only.sh`
