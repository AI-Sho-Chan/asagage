## 4) 2025-12-12（金）16:30 JST 週末バッチの状況
### 結論
- 12/12 16:30 JST の定例週末バッチは **走っていません**（出力もありません）。

### 原因
- VM 上の `~/run_weekend_only.sh` が Windows からの `scp` 経由で **BOM/CRLF 付き**になっており、cron から実行するとシェル解釈に失敗していました。
  - `~/cloud_logs/cron_stdout.log` に以下が記録：
    - `#!/bin/bash\r: not found`
    - `set: Illegal option -o pipefail`

### 対応
- `vm_run_weekend_only.sh` を **BOM無し**で管理し直し、VM 側は **リポジトリ内のスクリプトを bash で直接実行**する形に統一：
  - VM crontab：`30 16 * * FRI bash /home/shouichi_ikeda/asagage/vm_run_weekend_only.sh >> /home/shouichi_ikeda/cloud_logs/cron_stdout.log 2>&1`
  - `vm_run_weekend_only.sh` は日付引数（例：`20251212`）を受け取れる（バックフィル用）

### バックフィル（進行中）
- `bash ~/run_weekend_only.sh 20251212` を手動で開始（`tmux` セッションで継続運用）。
- 進捗確認（VM）：
  - `tail -n 60 ~/asagage/logs/nightly_status.txt`
  - `ls -t ~/cloud_logs/weekend_*.log | head`
  - `ps aux | grep -E "run_weekend_only|nightly_build_candidates|bt_opt30_forward" | grep -v grep`
