# handover_20260202

## 背景

- **ASAGAKE を DEMO で回している間、他のExcel作業が定期的に止まる（Excelがビジーになる）**という問題が発生。

## 原因（結論）

- Windows の Excel は「複数のブック・複数のExcelウィンドウ」が **同じ `EXCEL.EXE` プロセス**で動くことがあります。
- その状態で ASAGAKE の **タイマーVBA（`AutoTickV2`）**が定期実行されると、同じプロセス内の他ブック操作も巻き込まれて止まります。

## 対策（実装済み / 推奨）

### 1) 朝起動タスクは「ASAGAKE専用Excelインスタンス」を必ず作る

- `Step1_Morning.vbs` を修正し、既存Excelにアタッチせず **必ず `CreateObject("Excel.Application")`** で新規Excelを起動するようにした。
- これにより、朝起動で開いたASAGAKEが他のExcel作業をブロックしにくくなる。

### 2) 手動で開く場合も「新しいExcelで開く」を徹底

- エクスプローラーで `ASAGAKE.xlsm` をダブルクリックすると、既存Excelに入ってしまい、再発しやすい。
- **必ず専用起動スクリプト**で開く（/xで新規プロセスを強制）。
  - `scripts/open_asagake_isolated.ps1`
  - `scripts/open_asagake_isolated.cmd`

### 3) DEMOは更新頻度を落として“固まりにくく”する（設定追加）

- `state/strategy_rules.ini` に DEMO用の更新間隔を追加（デフォルトは軽め）。
  - `demo_autotick_interval_sec=15`
  - `demo_calc_interval_sec=10`
  - `demo_driver_trend_interval_sec=30`
  - `demo_bridge_ms_interval_sec=15`
- `excel/AutoTraderAdvanced.bas` 側でこれらを読み、DEMO時の負荷を下げるようにした。

## 動作確認（ユーザーが確認できるポイント）

- タスク起動後に、タスクマネージャーで `EXCEL.EXE` が2つ以上になり、ASAGAKEが別プロセスで動いている。
- `C:\AI\asagake\logs\vba_events.log` に `scheduled interval_sec=15`（DEMO時）が出る。

## 追加対応（Excelがビジーになる件）

### 症状
- ASAGAKE を DEMO で動かしていると、同じ Excel（同じウィンドウ/同じEXCEL.EXE）で開いている **他のブックも定期的に操作不能**になる。

### 原因
- DEMO 中は `AutoTickV2` が数秒ごとに動きます。
- Excel のマクロは **同時に1つしか実行できない**ため、同じ Excel プロセス内に他ブックがあると、他ブック側も「待たされて固まっている」ように見えます。

### 対策（壊さずに追加）
1) **AutoTickV2 に安全ガードを追加**
   - 同じ Excel プロセス内で他ブックが開かれている場合は、自動ループを止めて `IDLE` に戻します（他ブックを巻き込まないため）。
2) **朝起動（Step1_Morning.vbs）の隔離強化**
   - `IgnoreRemoteRequests=True` を設定し、ASAGAKE専用のExcelインスタンスに他ファイルが入り込みにくくしました。
3) **別インスタンスで他作業Excelを開く（推奨運用）**
   - ASAGAKE を動かしたまま他のExcel作業をする場合は、別のExcelを開いてください。
   - 例：`excel.exe /x` で別のExcelを起動してから、そこで他のファイルを開く。
   - 便利スクリプト：`scripts/open_excel_new_instance.ps1`（必要なら使う）。

### 確認方法
- `C:\AIsagake\logsba_events.log` に `AutoTickV2` のログが出ます。
- 他ブックを同じExcelで開いたときに `warn: other workbooks detected` が出て、ASAGAKE が `IDLE` に戻れば、巻き込み防止が効いています。
