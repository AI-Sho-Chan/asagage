# Handover 2026-01-24

## 1) 「Import Candidates で 1銘柄しか出ない」事象
### 何が起きていたか（再現性のある証拠）
- `logs/vba_events.log` に `ImportCandidatesV2 done imported=1` / `done imported=0` が複数回記録されていた。
  - つまり「表示が1行に見える」だけでなく、実際に読み込み元の `output/excel/candidates_nextday.csv` が 1行相当まで縮んだタイミングがあった。
- `output/excel/candidates_nextday.csv.backup_...` に **2行（ヘッダ+1行）**のバックアップが残っている（縮小の痕跡）。

### 原因（2つ）
1) **Excel 側の表示（フィルタ/非表示）問題**
   - `NewDashboardV2` にフィルタが残っていたり、行が Hidden になっていると、取り込み自体は成功しても「1行に見える」ことがある。
2) **候補CSVそのものが “1行” に縮む問題（根本原因）**
   - `scripts/run_nightly_candidates.ps1` は nightly の成否に関係なく、最後に
     - `python tools/aggregate_candidates_today.py --output output/excel/candidates_nextday.csv`
     を毎回実行する。
   - `aggregate_candidates_today.py` の旧挙動だと、候補が一時的に少なくなった日に `candidates_nextday.csv` を 1行で上書きしてしまい、その状態がしばらく続くことがあった。

### 対応（実装）
- `excel/AutoTraderAdvanced.bas`:
  - `ImportCandidatesV2` の冒頭でフィルタ解除＆行のHidden解除を行い、「取り込んだのに見えない」を防止。
- `tools/aggregate_candidates_today.py`:
  - **「5行未満に縮む書き換え」を禁止**し、縮みそうな場合は `candidates_nextday_last_good.csv` / `candidates_nextday.csv.backup_*` から復元するガードを追加。
  - これにより「一度1行に縮んだら、しばらく1行のまま」という状態を止めた。

### 使い方（現場手順）
1) `output/excel/candidates_nextday.csv` が 5行以上あるか確認
2) Excelで `SetupDashboardUIV2` を1回実行
3) `Import Candidates` ボタン

## 2) 朝 8:50 の自動起動（Asagake-MorningDemo）で「開かない/ロックされる」件
### 現状の仕様
- `Asagake-MorningDemo` は `Step1_Morning.vbs` を実行し、Excelを起動して `ImportCandidatesV2` → `StartDemoV2` を呼ぶ。
- **意図的に Excel を開いたままにする**（タスクはすぐ終了するがExcelは残る）設計。

### 「通知は来たが画面に出ない」「読み取り専用になる」典型原因
- Excelが **バックグラウンド/別セッション**で起動している、または既に起動済みでウィンドウが前面に出ていない。
- 結果として `ASAGAKE.xlsm` がロックされ、手で開こうとすると「他ユーザー使用中/読み取り専用」になる。

### 切り分け（PowerShell）
- Excelが開いているか確認:
  - `Get-Process EXCEL | Select Id,MainWindowTitle`
  - `Get-CimInstance Win32_Process -Filter "Name='EXCEL.EXE'" | Select ProcessId,SessionId,CommandLine`

### 対応の方向性
- タスクが「ユーザーがログオンしている時だけ」＋「PCをスリープ解除して実行」になっていることを確認する。
- それでも Excel が見えない場合は、既存Excelを前面に出す（Alt+Tab）か、不要な Excel を終了してから起動する。

### 「タスクスケジューラを管理者として起動」方法
- PowerShell から:
  - `Start-Process taskschd.msc -Verb RunAs`
