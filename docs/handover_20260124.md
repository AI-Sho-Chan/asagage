# Handover 2026-01-24

## 1) Import Candidates で「1銘柄しか見えない」問題

### 症状
- `ASAGAKE.xlsm` の `Import Candidates` を押すと、候補CSV（`output/excel/candidates_nextday.csv`）に複数行あるはずなのに、シート上は **1行（またはごく少数）しか見えない**ことがある。

### 原因（ほぼ確定）
- `NewDashboardV2` に **フィルタ（AutoFilter）や行の非表示が残っている**と、Import 自体は複数行書けていても、表示がフィルタされて「1行しか入っていないように見える」。
- `logs/vba_events.log` 上では `done imported=27` のように **複数行をImportしたログが残っているのに、画面が1行に見える**ケースがあるため、表示側（フィルタ/非表示）原因が濃厚。

### 対応（VBA）
- `excel/AutoTraderAdvanced.bas` の `ImportCandidatesV2` 冒頭に、候補行領域を「見える状態」に戻す処理を追加。
  - 既存の Import ロジック自体は変更せず、**壊さずに足す**。
  - 追加した処理:
    - `ShowAllData` / `AutoFilterMode=False` でフィルタ解除
    - `DASH2_DATA_START` 以降の行を一定範囲 unhide

### 適用手順（ユーザー操作）
1. Excel を完全に閉じる（バックグラウンドExcelも含む）
2. `C:\AI\asagake` で次を実行:
   - `powershell -ExecutionPolicy Bypass -File .\scripts\update_asagake_vba.ps1`
3. Excel で `ASAGAKE.xlsm` を開く
4. VBAで `SetupDashboardUIV2` を1回実行
5. `Import Candidates` を実行して行数が増えるか確認

## 2) 朝8:50タスク：起動メッセージは来るのにExcelが見えない / ASAGAKEがロックされる

### 状況整理
- 朝タスクは `Asagake-MorningDemo`（`wscript.exe C:\AI\asagake\Step1_Morning.vbs`）で、設計上は **Excelを起動してImport→Demo開始してから「Excelを開いたまま」**にする。
- Excelが既に開いていると、手動で `ASAGAKE.xlsm` を開くと「他ユーザーが使用中」等の表示になる（=その時点でブックは既に開かれている）。

### 確認コマンド（ロック原因の切り分け）
- Excelが既に開いているか:
  - `Get-CimInstance Win32_Process -Filter "Name='EXCEL.EXE'" | Select-Object ProcessId,SessionId,CommandLine`
  - `CommandLine` に `C:\AI\asagake\ASAGAKE.xlsm` が出ていれば、既に開いているので「手動で2重に開けない」のが正常。

### 対応（運用）
- まずはタスクの意図どおり「朝タスクで開いたExcel」を使う（タスク実行後はタスクバー/Alt+TabでExcelを探す）。
- もし見えない/閉じたい場合は、Excelを終了（最終手段はタスクマネージャで EXCEL.EXE を終了）。

### タスクスケジューラを管理者で開く
- PowerShell:
  - `Start-Process taskschd.msc -Verb RunAs`

## 3) 中間評価（DailyReplayが“no trades”になりがちな点）

### 事実
- `analysis/daily_replay_*.json` / `analysis/daily_replay_*_mail.txt` を見る限り、
