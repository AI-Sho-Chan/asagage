# 引継ぎ 2025-12-24（DecisionTrace / Bridge v1 の土台）

## 目的（今の仕組みを壊さずに“足す”）
- **監査できるログ（DecisionTrace）** を先に決めて、後から「なぜその注文になったか」を追えるようにする。
- 将来 **Excel/VBA を薄くする**（判断はPython、Excelは“注文を流すだけ”）ための **CSVインターフェース（Bridge）** の形を先に固定する。

## 今回入れたもの（仕様 v1）
### 1) スキーマ定義（JSONとして書いた .yaml）
`schemas/` に以下を追加：
- `schemas/decision_trace_dt_v1.yaml`（DT.v1）
- `schemas/market_snapshot_ms_v1.yaml`（MS.v1）
- `schemas/orders_cmd_oc_v1.yaml`（OC.v1）
- `schemas/execution_events_ee_v1.yaml`（EE.v1）

補足：
- `.yaml` 拡張子ですが、内容は **JSON** です（YAMLはJSONを含められるため）。
- 目的は **PyYAMLを増やさず** に、テストで読み取れるようにするためです。

### 2) Python 側のI/O骨格
`src/asagake_io/` を新規追加：
- `src/asagake_io/csv_schemas.py`：列順固定の定義（DT/MS/OC/EE）
- `src/asagake_io/csv_writer.py`：追記（append-only）用ライター、DT用ラッパ
- `src/asagake_io/atomic_writer.py`：OC（丸ごと置換）の tmp→rename 更新
- `src/asagake_io/validator.py`：ヘッダ・型の軽量チェック

### 3) DailyReplay に DT.v1 出力オプションを追加
`tools/simulate_daily_replay.py` に追加：
- `--decision-trace`：`analysis/decision_trace_YYYYMMDD.csv` に DT.v1 を追記出力
- `--run-id`：DTの run_id を手動指定（未指定なら自動生成）
- `--engine-version`：DTの engine_version を手動指定（未指定なら git short sha を試す）

**出力されるイベント種別（最低限）**
- `MARKET_SNAPSHOT`
- `FEATURES_COMPUTED`
- `FILTER_EVAL`
- `DECISION`
- `EXIT`

補足：
- DailyReplay は Yahoo 1分足ベースなので、`bid/ask` は空欄のままになります（将来、Excel(outbox)のMS.v1で埋める想定）。

### 4) VBA側の実装は “計画書のみ”
- `docs/bridge_v1_vba_plan.md`：inbox/outbox の3ファイルをVBAでどう読む/書くかの手順（疑似コード）

### 5) 最小テスト
- `tests/test_bridge_v1_schemas.py`
  - スキーマファイル（schemas/*.yaml）と `src/asagake_io/csv_schemas.py` の列順一致を検証
  - append-only 書き込みで **ヘッダが二重にならない** ことを検証
