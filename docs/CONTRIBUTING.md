# Contributing

- Always read `AGENTS.md` before making changes.
- Excel workbook policy: do not use openpyxl (or similar) to modify `SHINSOKU.xlsm`. Use VBA/COM scripts only. See `docs/codex.md` and `docs/handover_20251027.md`.
- Optional: enable repository Git hooks to activate the guard:
  - `git config core.hooksPath .githooks`
