## 2) DailyReplay が止まっていた原因と対応

### 原因

- ローカルPCの Git が **sparse-checkout 有効のまま**になっており、`tools/simulate_daily_replay.py` 等が作業ツリーに存在しない状態になっていた。
- その結果、`Asagake-DailyReplay`（Task Scheduler）が実行しても `python ... tools/simulate_daily_replay.py` が見つからず失敗していた。
- さらに `scripts/run_daily_replay.ps1` が `--date-tag` を渡していたが、`tools/simulate_daily_replay.py` は `--date` 仕様になっていた。

### 対応（コード）

- `scripts/run_daily_replay.ps1` を修正し、`--date` を使用するよう統一。
- ログ文字化け（UTF-16混入）を避けるため、PowerShell側ログ出力を `Out-File -Encoding utf8` に固定。
- `tools/simulate_daily_replay.py` に `--email/--recipient/--smtp` を追加し、メール送信を同一コマンドで実行可能にした。

### 対応（Git作業）

- `git sparse-checkout disable` を実行し、欠落していた `tools/` 配下を復元。
- 修正をコミット＆push:
  - `5b079efaaa` `Fix DailyReplay runner args and email sending`
