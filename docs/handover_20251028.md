# Handover Notes (2025-10-28) – Opt30 Optimizations Phase 1-3

## Implemented Highlights
- `scripts/bt_opt30_forward.py` now supports incremental caching, low-priority ticker suppression, ASHA pruning for coarse runs, Optuna Bayesian search for refine runs, and ineffective `J_th` band masking with persisted state under `state/`.
- Added CLI flags:
  - `--run-type`, `--cache/--no-cache`, `--cache-refresh`, `--enable-asha`, `--enable-bayes`, `--bayes-trials`, `--bayes-timeout`
  - `--mask-ineffective`, `--mask-window`, `--mask-threshold`
- Low-priority state saved to `state/opt30_low_priority.json`; ineffective band state to `state/ineffective_bands.json`. Reports are emitted per run (`low_priority_report.json`, `ineffective_bands_report.json`) in the run folder.
- Weekend runs automatically skip low-priority gating and ineffective-band masks but still update their histories.
- AutoTrader.bas を更新し、Start Auto 実行時に RSS 列の式が消えないよう SignalStatus/SignalKind 列の再適用ロジックを修正。実運用前に scripts/excel_install_macros.py で再インポートしてください。

## Nightly / Weekend Runner Updates
- `scripts/nightly_build_candidates.py` relays the new options. Use `--enable-asha`, `--enable-bayes`, `--mask-ineffective`, `--cache-refresh-weekend`, etc., when invoking.
- Weekend scheduler (`scripts/run_weekend_fullscan.cmd`) now runs with:
  - `--run-type weekend --enable-asha --enable-bayes --mask-ineffective --cache-refresh-weekend`
  - Bayesian trials default to `60` on weekend full scans.

## Operational Notes
- Caching:
  - Results stored under `cache/opt30/<code>/<plan>/<param_hash>/<data_hash>/result.json`.
  - `--cache-refresh` forces recomputation (applied automatically on weekend full scans when configured).
- ASHA:
  - Guarded by `--enable-asha`; uses `eta` (default `3`) and evaluates partial slices before promoting combos.
- Bayesian refine:
  - Requires `optuna`; script auto-disables with a log if unavailable.
  - Trials count configurable via `--bayes-trials`, timeout via `--bayes-timeout`.
- Ineffective bands:
  - Masking considers `J_th` buckets; average forward PF must exceed `mask-threshold` (default `1.05`) over the last `mask-window` runs to remain active.

## 2025-10-29 Updates — Mask & Optuna Sync
- Post-run automation（平日/週末共通）: `scripts/nightly_build_candidates.py` 完了時に `tools/analyze_param_stats.py` → `tools/update_ineffective_bands.py` → `tools/update_optuna_priors.py` を連続実行。完了を待たず翌朝6時バッチは不要になった。
