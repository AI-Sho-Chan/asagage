# handover_20251218.md

## 目的

- `ASAGAKE.xlsm` の `Import Candidates` が「候補が入らない/空になる」問題を潰し、今日の DEMO 動作確認（preplace→約定→TP/SL）に戻す。
- 16:30 のローカルナイトバッチが「走った/走ってない」「候補CSVが更新された/されてない」を判断できる状態にする。

## 結論（何が起きていたか）

- `C:\AI\asagake\output\excel\candidates_nextday.csv` は存在していましたが、**改行が LF のみ（CRLF なし）**で出力されていました。
- VBA の `Line Input #` はこの形式だと **ファイル全体を1行として読む**ことがあり、結果として
  - 取り込み0件
  - その後の「余り行クリア処理」で既存の候補行だけ消える
  という挙動になり得ます（ユーザーが見た「空になる」の原因）。

## 変更（コード）

- `excel/AutoTraderAdvanced.bas`
  - `ImportCandidatesV2` を **LF/CRLFどちらでも読める**ように修正（ファイル全体を読み、`vbLf` で分割）。
  - **取り込み0件の場合はシートをクリアしない**（最後に見えていた候補を残す）。
  - 取り込み開始/終了、取り込み件数、書き込み失敗を `logs/vba_events.log` に出すように強化。
  - `LogVbaEvent` の出力先を `C:\AI\asagake\logs\vba_events.log` に寄せ、場所ズレで追えない問題を回避。
- `tools/aggregate_candidates_today.py`
  - `to_csv(..., lineterminator=\"\\r\\n\")` を指定し、生成する `candidates_nextday.csv` を CRLF に統一。

## 変更（運用）

- ナイトバッチは 2025-12-17 16:30 に実行されていましたが、`logs/nightly_status.txt` が
