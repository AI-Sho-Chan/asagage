# 時間帯を区切る/区切らない比較（M0〜M3）メモ

目的：  
「時間帯を区切ってパラメータを探す（今の週末バッチのやり方）」が、  
「一日まとめて同じルールで売買する」より本当に良いのか、を同じ条件で比べる。

## 共通の前提（比較では必ず同じ）

ユーザー合意済み：
- 同時に持てるのは「1銘柄につき1ポジション」だけ
- いったん決済したら「再エントリーOK」
- 再エントリーまでの待ち時間：5分
- 同じ銘柄は1日最大2回まで

※この条件は「M0〜M3全部」に同じように適用する。

## 比較方式（案）

- **M0（区切らない）**：時間帯で区切らず、1日中同じ条件で取引
- **M1（大まかに区切る）**：例：寄り付き直後 vs それ以降
- **M2（前場/後場）**：午前と午後で分ける
- **M3（現行）**：AM15 / AM0930 / AM0945 / AM1015 / AM1030 …のように複数の時間帯で分ける

## 出力（比較表）に入れる項目（最低限）

推奨ファイル例：`analysis/method_daily_summary.csv`

- `date_tag`（日付：YYYYMMDD）
- `method`（M0/M1/M2/M3）
- `trades`（取引回数）
- `pnl_yen`（損益合計：円）
- `pnl_yen_mean`（1回あたり平均：円）
- `winrate`（勝率）
- `worst_trade_yen`（最悪の1回：円）
- `notes`（条件や例外のメモ）

## 注意（大事）

「本当に強い比較」をしたいなら、
- その日に存在した候補（その日の `candidates_for_YYYYMMDD.csv` 等）を使って、
- その日の次の取引日の1分足で回す  
（＝未来の情報を先に見ない）

ただし過去の候補が「今の週末バッチ」と仕様が違いすぎる場合は、参考度が落ちる。  
その場合は、まず「今の候補（同じ候補）」で M0/M3 の違いだけを見る（軽い検証）→その後、候補生成も含めた本格比較へ進むのが安全。
